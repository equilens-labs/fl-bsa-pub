# FL-BSA Public Artifacts (`fl-bsa-pub`)

This repository hosts **public, versioned, website-linkable** release artifacts for FL-BSA, published as **GitHub Release assets**.

## What This Repo Contains

- **Synthetic/demo-only** artifacts (reports + data) and technical publications generated by producer workflows.
- Integrity and provenance sidecars such as `SHA256SUMS.txt`, `manifest.json`, and
  `whitepaper_release.json` for each published release.
- These artifacts are **static samples** intended for download/review. They are **not** produced by a prospect's
  deployed FL-BSA appliance.
- Public GOLD bundles may include row-level synthetic/demo datasets plus validation/evidence scaffolding.
  They are public review fixtures, not customer data or customer evidence bundles.

## What This Repo Never Contains

- Customer datasets or customer evidence bundles.
- Logs, runner filesystem paths, credentials/secrets, or internal-only infrastructure details.
- Artifacts committed into git history (all publishables are **release assets**, not tracked files).
- Demo appliance images/builds. If an appliance route is separately approved, its exact handoff or
  Marketplace record governs distribution; this repository does not establish a standing route.

## License Scope

The repository-level [`LICENSE`](LICENSE) applies to the tracked repository
documentation and metadata.

Release assets are distributed separately through GitHub Releases. For those
assets, use the release's provenance sidecar, `SHA256SUMS.txt`, and release
notes as the asset-level source of truth for synthetic/demo disposition,
integrity, and usage context.

## Stable Link Contract (For Website)

For prerelease artifacts, use explicit versioned links:

- `https://github.com/equilens-labs/fl-bsa-pub/releases/download/<tag>/<asset>`

For non-prerelease artifacts only, GitHub’s “latest release” download URLs may be used:

- `https://github.com/equilens-labs/fl-bsa-pub/releases/latest/download/<asset>`

Do not use `/releases/latest/download/...` for RC or prerelease website links. GitHub excludes
prereleases from its latest-release endpoint.

## v5.0.8 Technical Whitepaper Prerelease

The source issue and workflow links in this section are operator-only
provenance because their repositories are private. Public readers can verify
the distributed bytes through the public release, sidecar, companion, and
checksums linked below.

The release owner approved the full technical whitepaper and its exact
verification companion in
[`fl-bsa#1812`](https://github.com/equilens-labs/fl-bsa/issues/1812). The
immutable
[`v5.0.8-technical-whitepaper-20260930`](https://github.com/equilens-labs/fl-bsa-pub/releases/tag/v5.0.8-technical-whitepaper-20260930)
prerelease contains exactly these four assets:

- [`whitepaper.pdf`](https://github.com/equilens-labs/fl-bsa-pub/releases/download/v5.0.8-technical-whitepaper-20260930/whitepaper.pdf)
- [`fl-bsa-v5.0.8-technical-companion.zip`](https://github.com/equilens-labs/fl-bsa-pub/releases/download/v5.0.8-technical-whitepaper-20260930/fl-bsa-v5.0.8-technical-companion.zip)
- [`whitepaper_release.json`](https://github.com/equilens-labs/fl-bsa-pub/releases/download/v5.0.8-technical-whitepaper-20260930/whitepaper_release.json)
- [`SHA256SUMS.txt`](https://github.com/equilens-labs/fl-bsa-pub/releases/download/v5.0.8-technical-whitepaper-20260930/SHA256SUMS.txt)

The 21-page paper is a public technical characterization of FL-BSA v5.0.8. It
covers the system architecture, metrics and decision rules, robustness
scenarios, security and threat boundaries, deployment controls, governance,
and regulatory mapping. The companion is the bounded public verification set:
it includes the exact structured inputs behind the paper, 40 scenario
contracts, and an offline verifier. The public PDF is 956,402 bytes with
SHA-256
`374fe04edf52359976170f4115762b6b11d90fdc21cb340f3de73749eaebb736`.

This is a technical publication, not campaign copy. Its evidence posture
remains `characterization_only`: customer- and promotion-evidence eligibility
are false, and no production-utility, certification/compliance, regulator,
Marketplace/GA, or claim-expansion authority is granted. Average Odds
Difference and Equal Opportunity Difference are unavailable because separate
ground-truth and prediction provenance is absent; neither is represented as a
numeric zero. Decision-controlling groups, ratio, threshold, and review status
are presented together. All 40 robustness contracts pass, while the reported
mean utility AUC is `0.689630` and 36 of 40 runs are below `0.70`; the paper
therefore does not claim established production utility.

Official source build
[`36763209122`](https://github.com/equilens-labs/fl-bsa-whitepaper/actions/runs/36763209122)
produced the reviewed four-file source. Dry-run publisher workflow
[`36766710848`](https://github.com/equilens-labs/fl-bsa/actions/runs/36766710848)
scanned and uploaded the exact source with zero rewrites. Publication workflow
[`36767857541`](https://github.com/equilens-labs/fl-bsa/actions/runs/36767857541)
promoted only that reviewed dry-run artifact. The release is a GitHub
prerelease and is excluded from `latest`. All four unauthenticated asset URLs
returned HTTP 200 after publication, and fresh downloads matched the reviewed
bytes and `SHA256SUMS.txt`.

## Exact Stable v5 Disposition

The RC9 assets listed immediately above are an RC9-era corrected, non-commercial technical-proof
prerelease. They are not a public distribution of the product repository's exact stable `v5.0.0`
release.

No exact-stable `v5.0.0` public release is recorded in this repository. Do not infer stable public
availability, customer-evidence approval, general availability, certification, or Marketplace
publication from the RC9 assets. No exact-stable `v5.0.0` public-artifact approval is recorded in
the RC9 record. Retargeting public links to other exact-stable assets requires separately recorded
release-owner, legal/claims, and publication approval; this record does not constrain an
owner-approved removal or retarget of historical RC9 links.
